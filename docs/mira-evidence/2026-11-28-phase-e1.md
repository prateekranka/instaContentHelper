## App changes

- Home speaks first. It lists each unfinished Reel with progress and the current Reel progress action. It excludes archived Reels, fully filmed Reels and empty projects. The idea card carries the existing request, microphone and chips when there is no open work.
- Home reads existing Instagram insights. It shows available headline metrics and labels sample data. Home generation does not send the insights to AI.
- Deals accepts brief text and lets the creator save it as a Reel brief. My Brand shows the saved profile, existing Reel briefs and All Reels. Profile stays in the toolbar. All Reels includes archived Reels through its existing filter.
- Ask Mira sits in a bottom safe-area inset on the main tabs and on Reel screens. The existing tab bar clearance still applies to scroll content. Home and My Brand use the existing idea request. A Reel uses the current screen's reviewed change action. Deals opens a brief draft.
- The Reel flow shows the step from the active location. Approval opens the shot list. The filming action remains available only for a current list and approved words. The list shows edited length, shot count, places, props and audio before the shot details.
- All saved fields and raw values stay the same. Saved `today` and its route stack map to Home. Saved `projects` and its route stack map to My Brand. Deals restores the previous saved tab if the app closes there. No saved field was added.

## State machines

| Machine | State | Event | Result and next action |
| --- | --- | --- | --- |
| Home feed | Empty | Work changed | Read the current library. Show Make today's Reel while no unfinished Reel has work. |
| Home feed | Continuing | Work changed | Keep each unfinished Reel with work. Use each Reel's progress action. Return to Empty when none remain. |
| Location | Home | Select or open tab. Set path. Push. Show Words or Show Plan. Remember or remove Reel. | Home uses the saved Today path. Show Plan opens the editor at Shots. |
| Location | Deals | Same location events | Deals opens the brief entry screen. The existing saved tab and both saved paths remain available. |
| Location | My Brand | Same location events | My Brand uses the saved Projects path and gives access to All Reels. |
| Task step | Idea | Open a location | Step 1. Choose an idea or make a current idea card. |
| Task step | Words | Open a location | Step 2. Use the script editor or the Words state to draft, change or approve the words. |
| Task step | Shot list | Open a location | Step 3. Update a stale list, approve the words or go shoot when both are current. |
| Task step | Shoot | Open a location | Step 4. Record filming progress or finish. |
| Task step | Upload | Open a location | Step 5. Show the current Done screen. Upload and post are later steps. |
| Reel progress | Ready | Saved work changed | The next step is Review your filming plan. |
| Words | Reviewing, Ready, Applying shots | Approve, Review Plan or Shots Applied | Keep the approval or saved-result checks. Open the shot list before filming. Other request and proposal states keep their previous effects. |

The state tables have the full event coverage. [Mira state machines](../state-machines.md)
