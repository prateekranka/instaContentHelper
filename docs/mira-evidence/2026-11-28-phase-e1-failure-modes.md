# Mira Phase E1 failure modes

| Area | What can break | Verification |
| --- | --- | --- |
| Tabs and saved place | An earlier Today or Projects selection opens the wrong tab, drops a saved route, or fails to open the library. An archived Reel disappears. | Open an earlier library, check both mapped paths, and open an archived Reel from All Reels. Relaunch after switching tabs. Compare the saved keys and raw values with the base revision. |
| Empty Home | An empty project gets a Continue card, or the idea request loses chips, voice, consent, Stop, wait steps, retry, or pictures. | Open an isolated sample library, including an empty project, and check the idea card. Run S1–S3 and D2 sample journeys. |
| Home with work | Home hides an unfinished Reel, shows a finished or archived Reel, or offers the wrong action after an edit or undo. | Prepare Reels at different steps. Check the Continue cards, action labels, progress and destinations. Run approval regressions B1–B3. |
| Instagram | An unconnected account sees invented numbers, or Home asks to connect, changes the session or sends metrics to AI. | Check sample Home without an account, the live Home insights card and the Profile Keep checks. Inspect the existing read path and generation inputs. |
| Ask Mira | The bar covers the final scroll control, hides behind the tab bar or keyboard, leaks a draft into another Reel, or sends a request before review. | Check the keyboard and last content in each main tab and Reel step. Route a typed message to the correct draft. Check that changing tabs or Reels does not carry the text into a different action. |
| Task flow | The counter disagrees with the visible step, an old route bypasses approval, or a relaunch resumes the wrong shot or screen. | Select an idea, check step 2, advance to the shot list and film one shot. Relaunch at each stage. Undo approval during filming and check that filming controls close. |
| Shot list | The summary misses timing, location, props or audio. The last shot is hidden. A stale or unapproved plan can start filming. | Check the summary and last shot on one scroll page. Use the shooting button only with a current plan and approved words. Repeat with invalidated approval or an out-of-date plan. |
| Data and runtime settings | Build or install loses saved projects, consent or Instagram. Required runtime keys are absent. | Build both targets. Check only whether the five Info.plist values are present. Keep checks run before the in-place install, after it and after testing. |
| Cost and regression | A live retry starts duplicate text requests or exceeds the picture cap. | Reserve each live batch in the request ledger. Count observed pictures and retain the ledger for any test-only retry. Run B4 and B5 with sample data only. |
