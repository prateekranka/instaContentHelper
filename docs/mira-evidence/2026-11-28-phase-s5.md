## Limits

- TLC checks bounded models. Swift, SQL, and worker behavior need their own runtime checks. The shared suite models S1 and D2 rules. Phase E has [separate model evidence](tla-e/).
- The table check verifies Swift case names. Review the events, conditions, and next steps against the source. The write rule checks direct Swift syntax for known fields and owners. Indirect writes through key paths or inferred aliases can need separate review.
- Claude will verify the hosted GitHub Actions run on the PR. The branch and logs remain local. The public tracker update is deferred under the task restriction on live services.
