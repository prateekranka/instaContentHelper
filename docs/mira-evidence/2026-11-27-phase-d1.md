# Phase D1 evidence — Today, colors, text size, wait screen, idea cards (2026-11-27)

Branch: `claude/mira-phase-d-today`, from `main` at `b4fe343`. Failure modes were written first: [2026-11-27-phase-d1-failure-modes.md](2026-11-27-phase-d1-failure-modes.md). App only: no AI calls added, no server change, no deploy.

## What changed

- **Today**: a greeting and one question, "What can you film today?". The text box shows 2–4 lines and has a visible edge. A large microphone button uses the existing on-device speech input. It asks for permission only on a tap, and the spoken words go into the box, where she can edit them. A "Done" button above the keyboard closes the keyboard. The chips Gym · Home · Outside · 10 min · 20 min add or remove their words in the box: one place and one time at most. "Outside" now sets the place. There is one main button. "Continue" is a small card under it, and it does not show for an empty project.
- **Plan step by step and the example notebook** moved to Profile → "Other ways to start". The step-by-step button says that it opens in the Projects tab. The sheet closes first. No saved project is changed.
- **Colors and text**: app-owned UI is black, white and neutral gray, as CLAUDE.md says (Bobby chose this on 2026-11-27). Olive is removed everywhere, also on the sign-in screen. The main button is near-black on light and near-white on dark, and it gets smaller by a small amount when pressed (no movement with Reduce Motion). The text box style has a fill and an edge in both modes. The root `.font(.system(size: 18))` is removed, so the system text styles and Dynamic Type work. Text buttons ("Change something", Projects row actions, Profile start options) have a button shape.
- **Wait screen**: the idea cards screen shows "Idea 1 / 2 / 3" buttons with a status mark (ready, being made, did not load), "N of 3" and "About 1 minute" while an idea is being made. A card that is not ready is a placeholder card: "Mira is making idea N of 3", gray shapes and three steps. The server does not send sub-steps yet (D2), so only "Finding an idea" shows as the current step until the card is ready. Each card shows as soon as it is ready. One success haptic plays when the first idea becomes ready. There is no pulsing animation.
- **Idea cards**: a side-to-side carousel with the next card at the edge. "N of 3" text and the idea buttons replace the dots, so the idea 3 dot problem is gone. Each "Make this one" button has its own identifier (`mira.today.makeCard.N`), because two cards can be on screen at the same time.
- **Demo only**: the request "Demo slow cards" makes the demo cards arrive after about 5, 11 and 17 seconds, so the e2e can see the wait screen.
