## Voice input

| State | Events and result | Next action |
| --- | --- | --- |
| Idle | A tap starts a new permission check with an attempt ID | Use microphone |
| Asking permission | A matching reply starts recording, records a denial or reports a failure. Leaving cancels this attempt. | Wait |
| Denied | A return from Settings with both permissions granted makes the microphone available | Open Settings |
| Recording | Matching timer and recognition callbacks update the session. Stop, completion, interruption or the time limit ends capture. | Stop recording |
| Finishing | Release the audio resources. Return to idle after speech or show a failure if no words were captured. | Wait |
| Failed | A tap starts a new attempt | Use microphone |

Today and the voice note field use the same actions and status text. The speech recognizer still requires on-device recognition.

## Instagram insights

| State | Events and result | Next action |
| --- | --- | --- |
| Unopened | Start a read | Wait |
| Loading | Accept the current result, fail with a message, or restore the previous result on cancellation | Wait |
| Connecting | A matching login callback starts an insights read. An error shows a message. Dismissal returns to the connection prompt. | Wait |
| Loaded | Show the existing disconnected, personal, permission needed, no data or report result | Connect Instagram or check again, according to the result |
| Load failed | Keep a prior report when available and retry the read on request | Check again |

## Load and save

| State | Events and result | Next action |
| --- | --- | --- |
| Unopened | Begin opening the library | Wait |
| Opening | Report a completed read or a typed open failure | Wait |
| Open failed | A damaged library or a copy restored from backup can be opened again. A newer version requires an app update. Other read errors show their message. | Try opening saved work again or update Mira |
| Loaded | Save success clears a save error. Save failure shows its message. General app alerts can be shown and dismissed independently. | Continue |

The repository still copies damaged primary files before recovery, restores the same backup bytes and requires another open. Save still decodes the primary file before replacing it or its backup. A newer-version file remains untouched. The damaged-file fixture creates only new files in a named Debug sample library.

## AI consent

| State | Event and result | Next action |
| --- | --- | --- |
| Not asked | Read finds no consent record. A live request opens the permission question. | Review AI permission |
| Allowed | Read finds a current accepted record. The live request can proceed. | Continue |
| Declined | Read finds a current declined record. Today can show the review action after a blocked request. | Review AI permission |
| Out of date | Read finds an older consent version. The app asks again before permitting a live request. | Review AI permission |

Allow and Decline still write the same record for the same workspace and creator. The Debug overrides return synthetic records and ignore writes to the override store.

## AI request and words

| State | Events and result | Next action |
| --- | --- | --- |
| Sending or working | A valid start or status reply can report server backoff | Stop |
| Waiting to try again | The next status can keep waiting, resume work or return a result. Stop and reconnect use the existing job. | Stop |
| Other S2 states | Existing queue, cancellation, reconnect and proposal rules apply | Existing S2 actions |

The transport DTO reads optional `phase` from the job reply. Absent and unfamiliar string values use the usual working label. Only `waiting_to_retry` on an active job changes the label. Today cards, Your words and the project job show the retry text. Start, poll and cancel calls use the existing job ID. The document saves the original `MiraJob` type.
